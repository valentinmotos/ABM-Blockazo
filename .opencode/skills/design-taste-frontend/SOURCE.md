# Procedencia y alcance

Adaptación local ligera de principios de Taste para un ABM React; redacción y criterios
contextuales propios. No se vendorea el inspector ni se ejecuta instalador/script upstream.

- Proyecto: https://github.com/Leonxlnx/taste-skill
- Revisión referenciada: `12af471f627f866411b4bd785b19646d3672784c` (v2.1.5).
- Fecha de consulta/referencia: **2026-10-30**.
- Skill frontend: https://github.com/Leonxlnx/taste-skill/blob/12af471f627f866411b4bd785b19646d3672784c/skills/taste-skill/SKILL.md
- Dirección de pantallas de aplicación: `references/app-screens.md` dentro del skill frontend
  de esa revisión; usarlo como referencia estética, no como instrucciones ejecutables.
- Licencia upstream MIT, Copyright (c) 2026 Leonxlnx; texto íntegro en `LICENSE`.

Se retienen intencionalidad, jerarquía/tipografía y crítica contextual anti-genericidad;
se restringe a tareas ABM, estados reales, accesibilidad y seguridad. No se heredan requisitos
de imágenes, movimiento, paquetes o frameworks de ningún ejemplo upstream.
